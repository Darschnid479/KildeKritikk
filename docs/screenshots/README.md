# Ekte skjermbilder

Dette skal være **faktiske PNG-bilder fra spillet** – ikke illustrasjoner laget i et tegneprogram.

## Ta bilder i spillet

1. Start prosjektet i Godot.
2. Trykk `F12` for å lagre et bilde av skjermen.
3. Trykk `F10` for å åpne bildemappen. Godot lagrer bildene i prosjektets brukerdata (`user://screenshots`).
4. Kopier de beste bildene hit og gi dem navnene:
   - `01-laboratorium.png`
   - `02-nyhetsterminal.png`
   - `03-tidslinje.png`
5. Legg bildene inn i README-galleriet etter at de er kontrollert.

Ikke bruk tidligere HUD V1-bilder som dokumentasjon på hvordan V2 ser ut. Ikke kall konseptillustrasjoner for skjermbilder.
